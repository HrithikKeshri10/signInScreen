# Sign In Screen

A React Native sign-in screen built with Expo, recreated from a design reference. Built using only core React Native components — no UI libraries.

## Screenshot

![Sign In Screen](./screenshot.png)

## Features

- App logo section
- Heading and subheading
- Email input field (with focus state)
- Password input field
- Sign In button
- Social login buttons (Facebook, Google, Instagram)
- Sign Up and Forgot Password text actions

## Tech Stack

- React Native
- Expo (`expo-router`)
- `@expo/vector-icons` for icons
- TypeScript

## Getting Started

```bash
npm install
npx expo start
```

Then scan the QR code with the Expo Go app, or press `i` / `a` to open in the iOS simulator / Android emulator.

## Notes

This is a UI-only implementation focused on layout, spacing, alignment, and typography. The form fields and buttons are not wired to any backend.
